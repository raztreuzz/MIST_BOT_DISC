# MIST

![MIST logo](docs/assets/mist.png)

Bot de Discord para música y listas guardadas.

## Requisitos

- Python 3.12
- Poetry
- Un bot de Discord configurado

## Ejecutar

```bash
poetry install
poetry run python -m app.bot
```

## Comandos

### Música
- `/join`
- `/leave`
- `/play`
- `/pause`
- `/resume`
- `/stop`

### Listas
- `/list_create`
- `/list_add`
- `/list_show`
- `/list_play`
